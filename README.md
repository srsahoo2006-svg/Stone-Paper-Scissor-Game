# ✊🖐️✌️ Stone Paper Scissors

> *Yeah, I built this from scratch. No frameworks, no libraries — just plain HTML, CSS, and JavaScript doing their thing.*

---

## 🎮 What's this about?

A classic **Stone Paper Scissors** game that runs right in your browser. Simple, fun, and honestly kind of addictive once you start playing. You click, the computer picks, and one of you wins. That's it. But the little details make it feel really good.

---

## ✨ Features

- 🖱️ **Click to play** — just pick your move and the computer responds instantly
- 🤖 **Computer opponent** — randomised picks every round (no cheating, I promise)
- 📊 **Live score tracking** — wins, losses, and ties are all counted
- 🎨 **Clean UI** — designed and styled fully by hand, no templates
- ⚡ **No dependencies** — pure HTML, CSS & JS. Open and it just works.

## 🚀 How to run it

Genuinely couldn't be simpler:

1. **Clone the repo**
   ```bash
   git clone https://github.com/your-username/stone-paper-scissors.git
   ```

2. **Open the folder**
   ```bash
   cd stone-paper-scissors
   ```

3. **Launch it** — just open `index.html` in your browser

   *Or if you have VS Code, use the Live Server extension for a smoother experience.*

No installs. No `npm install`. No setup. Just open and play.

---

## 🕹️ How to play

1. You'll see three buttons — **Stone**, **Paper**, and **Scissors**
2. Click whichever one you want to throw
3. The computer makes its pick at the same time
4. The result shows up instantly — win, lose, or tie
5. Scores update automatically, keep playing as long as you want

### The rules (just in case)
| Your Pick | Computer Pick | Result |
|-----------|--------------|--------|
| ✊ Stone   | ✌️ Scissors   | You Win! |
| 🖐️ Paper   | ✊ Stone       | You Win! |
| ✌️ Scissors | 🖐️ Paper      | You Win! |
| Same      | Same         | It's a Tie |

## 💡 What I learned building this

Honestly this was a great little project to practice:

- **DOM manipulation** — updating scores, results, and UI states dynamically
- **Event listeners** — handling click events cleanly
- **Random logic** — using `Math.random()` for the computer's move
- **CSS layout & design** — making something look decent from scratch, no help from frameworks

It's small, but it covers a lot of the fundamentals in a really satisfying way.
